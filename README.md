# JTE Recruit Website

![JTE Recruit](https://cqkzlykkshlzemiiloeo.supabase.co/storage/v1/object/public/jte-images/hero/hero-image.png)

Official company website for JTE Recruit Pte Ltd, a Singapore-based recruitment agency specializing in talent acquisition across Banking, Engineering, Healthcare, and more.

**🌐 Live Site:** [https://eugeneteo88.github.io/jte-recruit-website/](https://eugeneteo88.github.io/jte-recruit-website/)

## ✨ Features

- **Responsive Design** - Optimized for desktop, tablet, and mobile
- **Service Showcase** - 8 core recruitment services with detailed modals
- **Team Section** - Interactive team profiles with hover effects
- **Testimonials** - Carousel showcasing client reviews (2 per slide on desktop)
- **Dark/Light Mode** - Toggle between color themes
- **Contact Form** - Direct email integration
- **WhatsApp Integration** - Floating chat button

## 🛠 Tech Stack

- **Frontend:** HTML5, Tailwind CSS (via CDN)
- **Icons:** Lucide Icons
- **Images:** Supabase Storage
- **Hosting:** GitHub Pages
- **Fonts:** Playfair Display, Inter (Google Fonts)
